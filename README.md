# PteroServerPanel

Panel web untuk mengelola satu server Pterodactyl melalui Client API.

## Setup

1. Gunakan Node.js 20 atau lebih baru.
2. Jalankan `npm install`.
3. Salin `.env.example` menjadi `.env` dan isi konfigurasi Pterodactyl.
4. Jalankan `npm start`.

API key hanya disimpan di backend. Jangan commit file `.env`.
